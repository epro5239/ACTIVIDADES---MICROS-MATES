# Práctica 16: Control Inteligente de Iluminación Bluetooth

## 📋 Descripción
Sistema de control inteligente de iluminación usando Raspberry Pi Pico W con comunicación Bluetooth, transistor 2N2222A, relevador 5V y sensor LDR.

## 🗂️ Estructura del Proyecto


## 🔧 Componentes
- Raspberry Pi Pico W
- Transistor NPN 2N2222A
- Módulo Relevador 5V
- Diodo 1N4007
- Fotorresistencia (LDR)
- Resistencias: 1kΩ y 10kΩ

## 📱 Funcionalidades
1. **Modo Manual**: Encendido/Apagado por Bluetooth
2. **Temporizador**: Configurable desde la app
3. **Modo Automático**: Control por luz ambiental (LDR)
